Pelawan E-Library

Sistem manajemen perpustakaan digital untuk mendukung budaya literasi di lingkungan sekolah.

Versi 2.0.0 — Kompetisi Duta Literasi
Versi Aplikasi
v2.0.0
Pembaruan terakhir menghadirkan fitur gamifikasi Kompetisi Duta Literasi dengan tiga kategori papan peringkat.
Dikembangkan Oleh
Komunitas ILMU KETAK
Komunitas mahasiswa yang mengabdi melalui pemanfaatan teknologi digital untuk masyarakat.
Keamanan Sistem
Autentikasi JWT
Sesi pengguna terenkripsi dengan token, seluruh data tersimpan aman melalui akses privat (PAT).
Infrastruktur
Vercel Serverless
Dijalankan dengan arsitektur serverless modern untuk performa cepat & andal.

Teknologi yang Digunakan

Node.js Express-style API GitHub Contents API Vercel Serverless Functions JWT Authentication HTML5 & CSS3 Vanilla JavaScript
